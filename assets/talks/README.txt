appear automatically in the Talks section of the site:

  accs-placebo-poster.pdf

If you export a talk from PowerPoint/Keynote, use File > Export > PDF,
then rename the file to match one of the names above.

Want a different set of talks, or more than four? Open index.html,
find the "Talks" section, and copy one .talk-card block per talk —
just change the title, context line, and the PDF filename in the src.
